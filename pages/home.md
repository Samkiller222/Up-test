This whole page is written in plain text. Nobody on the team needs to touch HTML to change it.

## How this page works

The words you're reading live in a file called `index.md` in the GitHub repo. When someone edits it through the editor and hits **Save**, it becomes a commit on GitHub, and the website rebuilds itself within a minute or so.

## What you can do in the editor

- Write headings, **bold**, *italic* and lists
- Add links like [this one](https://github.com)
- Create brand-new pages that show up in the menu automatically

> Tip: every save is kept in GitHub's history, so nothing is ever lost — you can always roll back.
